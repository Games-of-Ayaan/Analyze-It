# ⚡ Analyze It — YouTube Video Intelligence Dashboard

Analyze It is a futuristic, UI-rich YouTube Analytics tool built with HTML, CSS, and JavaScript (powered by the YouTube Data API v3).
Paste any YouTube video link (even share or shorts links) and instantly visualize insights like views, reach, engagement, and estimated earnings — all wrapped in a sci-fi glass interface with animated charts and a neon grid background.

🚀 Features

🔗 Supports all YouTube URL formats (watch, shorts, embed, share)

🧠 Video intelligence: views, likes, comments, reach %, average watch time, and estimated earnings

💎 HD Thumbnail Downloader (hover to reveal button)

🧷 Lock feature – keep your video URL saved between sessions

📊 Interactive Chart.js visualizations (expandable, glossy, animated)

🌌 Cyber grid animated background with glowing blur glass UI

🧊 Glassy GitHub footer panel with source credit

⚙️ Lightweight, runs 100% client-side

💡 Getting Started
1️⃣ Clone the repository
`git clone https://github.com/Games-of-Ayaan/Analyze-It.git
cd Analyze-It`

2️⃣ Open the project

Just open the index.html file in your browser — no server setup needed.

3️⃣ (Optional) Replace API Key

Inside the `<script>` tag, find this line:

`const API_KEY = "YOUR_YOUTUBE_API_KEY_HERE";`


Replace it with your own YouTube Data API key.
Get one from the Google Cloud Console
